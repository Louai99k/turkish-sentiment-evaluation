# Third-party inputs and provenance boundary

This package distributes project source/configurations/instructions, not installed
dependency source, datasets, pretrained vectors, model weights, tokenizers,
manuscript templates, fonts or generated research outputs. Dependencies are
imported or separately acquired; this project's software license does not apply
to those third-party inputs.

## Review record and limits

Staged historical scientific files are byte copies of the project workspace's
source/configuration files. New replication tools are separate project files,
not edits to original experimental gates. Source lineage/hashes establish which
files were copied, not legal ownership. Read-only inspection of staged Python
source found no explicit upstream copyright/adapted-from/copied-from attribution
markers. Their absence is not proof that every line is independently authored.

The author has reported freedom to choose terms for original code he owns.
PolyForm Noncommercial1.0.0 and the Luay Kelani Required Notice cover only code
and associated software material he is entitled to license. Retain any applicable
upstream notices if additional borrowed material is identified. Do not infer
blanket third-party clearance or sole ownership from manuscript authorship.

Before actual public deposit, review any borrowed snippets, institutional/joint
rights and dependencies' applicable terms for the distribution actually made.
No such terms are replaced by this document. No vendored dependency assets are
needed for the present code-only boundary; adding any requires a fresh review.

## Separately acquired inputs

- Python/PyTorch, transformers/datasets/Hugging Face client, scikit-learn/SciPy,
  NumPy/pandas, plotting packages, regex and tqdm retain their own terms. The
  observed requirements are not a transitive lock or redistribution bundle.
- Winvoker data and each base model/tokenizer use upstream identities/license
  metadata in configurations. These metadata are not a new rights guarantee.
- Turkish fastText vectors must be acquired separately. The recorded local
  archive checksum is content identity, not proof of its original download path
  or permission to redistribute it. No vectors are included.
- Teke data, externally evaluated checkpoints/masks and historical private gates
  are excluded. Code paths referring to them do not supply redistribution rights.

Luay is performing publication himself. Neither that decision nor the reserved
DOI constitutes independent legal clearance;the Zenodo draft remains unpublished
