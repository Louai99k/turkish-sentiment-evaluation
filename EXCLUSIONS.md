# Package A exclusions

Scope locked 2026-10-11: code, configurations and instructions only.
Default-deny inclusion: only reviewed source/config/instruction files enter this
staging folder. Preparation is not redistribution/publication permission.

| Excluded | Disposition |
| --- | --- |
| Experimental results, metric/score tables, statistics, bootstrap outputs and scientific result manifests | Stay in research outputs and separate professor supplement; excluded even if accepted or rights-cleared. |
| All predictions/logits/decision-score files, including text-free IDs/labels/scores | Stay in research locations; no prediction-release option under package A. |
| Datasets, ZIP/XLSX/CSV corpora, split assignments, generated masks, manually reviewed texts | No data included. Document acquisition/reconstruction and configuration identity pins instead. |
| Trained/pretrained models, pickles, checkpoints, tokenizers/vector archives and caches | Stay locally or acquire from upstream under applicable terms; no model assets included. |
| Figures, PDFs, t-SNE/attention exports, screenshots, generated histories and other research assets | Article/supplement/research locations only; not code package. |
| Secrets: .env, tokens, credentials, keys, account/cloud settings | Never include. Inspect content as well as filenames. |
| Entire outputs/, failures, optimizer/resume state, caches and working logs | Local processing only; no blanket copy or compact-results exception. |
| Private notes, professor correspondence/draft snapshots, revision reviews and git/account metadata | Private research workspace, not code package. |
| Paper/Overleaf template, fonts/class/style, manuscript and professor supplement | Separate delivery products, not repository contents. |

Only source code, hand-authored configuration/instructions and code-package
inventory/security/license documentation may be included. Configs may name
upstream revisions and expected input hashes; this does not include referenced
scientific files. Programmatic local output generation is allowed, but generated
research outputs must remain outside the public staging folder.

Initial six staged source/config files and docs fit this narrower boundary;
nothing required removal. Round2 adds instructions/tools and prepares explicit
scientific source/import-closure staging. Freeze JSON containing measured
selection outcomes and private acceptance records remain excluded even though
they live under configs/ in the research workspace. Original sources may refer
to those missing private dependencies; instructions disclose this replay limit.
Original accepted artifacts unchanged. No completed secret scan, hash audit or
license clearance is claimed at the prepared-command checkpoint.
